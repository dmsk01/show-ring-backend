# Этап 1: Hello World с очередями ✅ ЗАВЕРШЁН

### Цель
Понять базовый цикл: Producer → Queue → Consumer

### Теория

```
[FastAPI]                    [RabbitMQ]                    [Worker]
    │                            │                            │
    │  1. publish("hello")       │                            │
    │ ─────────────────────────> │                            │
    │                            │  2. store in queue         │
    │                            │ ─────────┐                 │
    │                            │ <────────┘                 │
    │                            │                            │
    │                            │  3. deliver message        │
    │                            │ ─────────────────────────> │
    │                            │                            │
    │                            │  4. ack (подтверждение)    │
    │                            │ <───────────────────────── │
    │                            │                            │
    │                            │  5. delete from queue      │
```

**Зачем нужны очереди:**
1. **Асинхронность** — API отвечает мгновенно, тяжёлая работа в фоне
2. **Надёжность** — если воркер упал, сообщения не потеряются
3. **Масштабирование** — 10 воркеров читают одну очередь, нагрузка распределяется
4. **Развязка** — API не знает кто и как обрабатывает задачи

### Созданные файлы

- `app/config.py` — конфигурация через pydantic-settings
- `app/services/rabbit.py` — сервис для работы с RabbitMQ
- `app/routers/tasks.py` — POST /tasks/send эндпоинт
- `app/main.py` — lifespan для управления подключением
- `worker/worker.py` — потребитель сообщений
