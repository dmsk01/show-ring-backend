# Ключевые концепции RabbitMQ

### Основные термины

| Термин | Описание |
|--------|----------|
| **Producer** | Отправитель сообщений (твой FastAPI) |
| **Consumer** | Получатель сообщений (воркер) |
| **Queue** | Буфер для хранения сообщений |
| **Exchange** | Маршрутизатор, распределяет сообщения по очередям |
| **Binding** | Правило связи между exchange и queue |
| **Routing Key** | "Адрес" сообщения для маршрутизации |
| **Connection** | TCP соединение с RabbitMQ (дорогое, переиспользуем) |
| **Channel** | Виртуальный канал внутри connection (дешёвый) |

### Типы Exchange

| Тип | Поведение | Когда использовать |
|-----|-----------|-------------------|
| **Direct** | Точное совпадение routing key | Задачи конкретному воркеру |
| **Fanout** | Копирует во ВСЕ привязанные очереди | Уведомления всем сервисам |
| **Topic** | Паттерн routing key (`*`, `#`) | Гибкая маршрутизация по категориям |
| **Headers** | По заголовкам сообщения | Редко используется |

### Гарантии доставки

| Механизм | Описание |
|----------|----------|
| **Ack (acknowledge)** | Воркер подтверждает успешную обработку |
| **Nack (negative ack)** | Воркер сообщает об ошибке, сообщение возвращается в очередь |
| **Reject** | Отклонить сообщение (можно с requeue или без) |
| **Prefetch** | Сколько сообщений воркер берёт за раз |
| **Persistent** | Сообщения сохраняются на диск |
| **Durable queue** | Очередь переживёт рестарт RabbitMQ |
