# ShowTail — Платформа управления выставками животных

## Описание проекта

Альтернатива [ZOOпортал.pro](https://zooportal.pro/) и [Каштанка.ru](https://kashtanka.ru/) — единая платформа для управления выставками животных, питомниками и продажей щенков.

### Кто пользуется

| Роль | Что делает |
|------|-----------|
| **Клуб / Организатор** | Создаёт выставки по правилам РКФ, управляет расписанием, рингами, судьями, публикует результаты |
| **Заводчик** | Ведёт страницу питомника, публикует помёты, записывает собак на выставки |
| **Эксперт (судья)** | Получает назначения на породы, выставляет оценки и титулы |
| **Покупатель** | Ищет щенков, изучает родословные, находит проверенных заводчиков |
| **Рекламодатель** | Размещает баннеры, промо-объявления, рассылки |
| **Администратор** | Управляет справочниками, модерирует контент, смотрит аналитику |

> Один пользователь может совмещать несколько ролей (заводчик + судья, организатор + покупатель). Роли хранятся в таблице `user_roles` (many-to-many).

### Мультивидовая архитектура

Архитектура поддерживает любые виды животных (собаки, кошки, ...). Справочники пород, классов и выставочных правил привязаны к `animal_type`. Первой реализуется система РКФ (FCI) для собак. Правила для других видов добавляются как конфигурация и должны соответствовать законодательству РФ.

## Безопасность

### Progressive Rate Limiting (защита от спама и brute-force)

Все публичные эндпоинты защищены progressive rate limiting через Redis:

```
Механизм:
1. Каждый запрос учитывается по ключу: IP + endpoint (или user_id + endpoint)
2. При превышении лимита — 429 Too Many Requests + заголовок Retry-After
3. При повторных нарушениях — экспоненциальный рост блокировки:
   1-е нарушение: блок 2 сек
   2-е нарушение: блок 4 сек
   3-е нарушение: блок 8 сек
   ...
   N-е нарушение: блок min(2^N, 3600) сек (макс 1 час)
4. После 1 часа без нарушений — счётчик сбрасывается
```

| Эндпоинт | Лимит | Ключ |
|----------|-------|------|
| `POST /auth/login` | 5 / мин | IP |
| `POST /auth/register` | 3 / час | IP |
| `POST /ads/events` | 100 / мин | IP |
| WebSocket connect | 10 / мин | IP |
| Общий API | 60 / мин | user_id (или IP для анонимов) |

### Прочие меры

- **Refresh tokens в БД** — возможность отзыва при logout/блокировке
- **Email verification** — подтверждение email при регистрации
- **Password policy** — минимум 8 символов
- **File upload** — проверка magic bytes (сигнатура файла), не только MIME
- **Sanitization** — очистка пользовательского контента от HTML/XSS
- **WebSocket auth** — JWT передаётся первым сообщением, не в URL
- **Ad fraud protection** — дедупликация событий по IP + user_agent + time window
- **CORS** — настраивается при появлении домена (не на ранних этапах)

## Что идёт через RabbitMQ

### Task Queue (одно сообщение → один воркер)

| Задача | Зачем очередь |
|--------|--------------|
| Генерация PDF (каталоги, дипломы, сертификаты) | 5-30 сек, CPU-bound |
| Email/Push-рассылки | Массовая отправка, retry |
| Рекламные рассылки | Тысячи получателей, throttling |
| Обработка файлов (ресайз, watermark) | CPU-bound |
| Импорт/экспорт данных (CSV, Excel) | Минуты на больших объёмах |
| Верификация питомников | Асинхронный процесс |

### Fanout / Topic Exchange (событие → много подписчиков)

| Событие | Подписчики |
|---------|-----------|
| `show.registration_opened` | Email, push, лента, рекламный модуль |
| `show.results_published` | Email участникам, обновление профилей собак |
| `litter.announced` | Подписчики породы, поисковый индекс |
| `dog.title_earned` | Профиль собаки, профиль питомника |
| `ad.impression` / `ad.click` | Аналитика, биллинг |

### Scheduled Tasks (APScheduler)

| Задача | Расписание |
|--------|-----------|
| Напоминание о выставке | За 7 дней и за 1 день |
| Закрытие просроченных объявлений | Ежедневно |
| Очистка expired refresh tokens | Ежедневно |
| Обновление рекламной статистики | Каждые 5 минут |
| Очистка старых партиций ad_events | Ежемесячно |

## Стратегия изучения SQL

| Уровень | Где применяем | Примеры |
|---------|--------------|---------|
| **Raw SQL** (`text()`, asyncpg) | Аналитика, отчёты, сложные агрегации | Топ-10 собак по CAC за сезон, сводка организатора, рекламная аналитика |
| **SQLAlchemy Core** (select, join) | Динамические фильтры, поиск | Поиск щенков (порода + регион + цена), каталог выставки |
| **SQLAlchemy ORM** (модели, relationships) | CRUD, бизнес-логика | Создание выставки, запись собаки, профиль питомника |
