# Концепция: Сервис ветеринарных клиник

> **Статус:** будущий функционал, не входит в текущие 15 этапов.

## Зачем

Ветеринарные услуги — естественное расширение платформы для владельцев животных. На выставках требуются ветеринарные справки, прививки, чипирование. Интеграция ветклиник закрывает полный цикл: покупка → ветобслуживание → выставки.

## Интеграция с выставками

Ключевая точка интеграции — **проверка ветеринарных документов при записи на выставку**:

```
POST /shows/{id}/entries (запись собаки на выставку)
  │
  ├── Текущие проверки:
  │   ├── Возраст → допустимые классы
  │   ├── Порода → допущена к выставке
  │   └── Регистрация открыта
  │
  └── НОВЫЕ проверки (vet integration):
      ├── Вакцинация от бешенства — не просрочена на дату выставки
      ├── Чипирование — номер чипа совпадает с dog.chip_number
      └── Ветеринарная справка — выдана не более 5 дней назад (по положению)
```

### Уровни интеграции

**Уровень 1 (мягкий) — рекомендательный:**
- При записи — предупреждение "вакцинация просрочена", но запись разрешена
- Организатор видит список участников без актуальных документов

**Уровень 2 (строгий) — обязательный:**
- Запись невозможна без актуальной вакцинации и справки
- Автоматическая генерация ветеринарных требований при создании выставки

## Новые роли

| Роль | Что делает |
|------|-----------|
| `vet_admin` | Управляет профилем клиники, сотрудниками |
| `vet_doctor` | Заполняет ветзаписи, выдаёт справки |

> Добавляются в `user_roles` — пользователь может совмещать (заводчик + vet_admin).

## API эндпоинты (проект)

| Метод | Путь | Описание | Доступ |
|-------|------|----------|--------|
| POST | `/vet/clinics` | Зарегистрировать клинику | VetAdmin |
| GET | `/vet/clinics` | Поиск клиник (город, услуга) | Public |
| GET | `/vet/clinics/{id}` | Профиль клиники | Public |
| POST | `/vet/records` | Добавить ветзапись | VetDoctor |
| GET | `/dogs/{id}/vet-records` | Ветеринарная история собаки | Owner / VetDoctor |
| GET | `/dogs/{id}/vaccinations` | Прививки собаки | Owner / VetDoctor |
| POST | `/vet/certificates` | Выдать справку | VetDoctor |
| GET | `/dogs/{id}/vet-certificates` | Справки собаки | Owner |
| GET | `/dogs/{id}/show-readiness` | Готовность к выставке (ветчасть) | Owner |

## Уведомления

Интеграция с системой уведомлений (этап 9):
- Напоминание о ревакцинации (за 30 дней до истечения)
- Напоминание о плановом визите (за 7 дней)
- При записи на выставку — уведомление, если документы не в порядке

## Что нужно для реализации

- **Новые таблицы:** vet_clinics, vet_records, vaccinations, vet_certificates
- **Новые роли:** vet_admin, vet_doctor → добавить в ENUM user_roles
- **Изменения в show_rules.py:** проверка ветдокументов при записи
- **Seed данные:** стандартные вакцины (бешенство, чума, парвовирус, лептоспироз)
- **PDF генерация:** ветеринарные справки (интеграция с воркером на этапе 8)

## Этапность реализации

1. Профили клиник + поиск (аналогично питомникам)
2. Ветеринарные записи + вакцинации
3. Справки + интеграция с выставками (мягкий уровень)
4. Строгий уровень + автоматические проверки
5. Напоминания + уведомления
