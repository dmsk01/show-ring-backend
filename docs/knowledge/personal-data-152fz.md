# Персональные данные в коде: согласия, маскирование, обезличивание

Как требования 152-ФЗ «О персональных данных» превращаются в код Show Ring:
что хранить, что скрывать, что удалять и когда. Правило простое: всё, что
обещано в Политике конфиденциальности (`show-ring-frontend/src/sections/legal/`),
должно быть реализовано здесь — иначе документ вводит в заблуждение.

## Журнал согласий

Доказать получение согласия обязан оператор (ч. 3 ст. 9 152-ФЗ). Поэтому
согласие — не булево поле у пользователя, а строка журнала: кто, какую
редакцию документа, когда и откуда принял.

```python
await consent_svc.grant(
    db, user.id, ConsentKind.personal_data, ip=ip, user_agent=user_agent
)
# Повторный вызов с той же редакцией ничего не пишет — идемпотентно.
```

Отзыв — `UPDATE revoked_at`, а не `DELETE`: история «принял A → принял B →
отозвал» остаётся целиком.

## Редакция документа

`CURRENT_REVISIONS` в `app/services/consent.py` — дата текущей редакции
каждого документа. Меняешь текст Соглашения или Согласия — меняешь дату
здесь и в `LEGAL_REVISIONS` во фронте. Старые согласия перестают
считаться актуальными:

```python
missing_required(active)  # → ["terms"], если пользователь принимал старую редакцию
```

Фронт видит непустой `missing` в `GET /users/me/consents` и показывает диалог
подтверждения (`ConsentGate`).

## Согласие на распространение

Публикация ПДн для неограниченного круга лиц требует отдельного согласия
(ст. 10.1), молчание согласием не считается (ч. 8). В коде это флаг у
конкретной публикации и маскирование в ответе:

```python
return hide_private_contacts(
    ClassifiedResponse.model_validate(obj),
    owner_id=obj.author_id,
    contacts_public=obj.contacts_public,
    viewer=viewer,           # get_current_user_optional
)
```

Владельцу и админу контакты отдаются всегда — иначе форма редактирования
получила бы `null` и затёрла бы контакты при сохранении. Включить флаг может
только сам владелец: согласие даёт субъект данных, а не модератор.

Новая ручка, отдающая чужие контакты наружу, обязана пройти через
`hide_private_contacts`.

## Обезличивание вместо DELETE

Удалить строку `users` нельзя: на неё ссылаются выставки, записи и кампании
с `ondelete="RESTRICT"`. Поэтому аккаунт обезличивается — из строки и
связанных таблиц уходит всё, что указывает на человека:

```python
user.phone = None
user.email = f"deleted-{uid.hex}@deleted.invalid"   # CHECK: email OR phone
user.is_active = False                              # get_current_user → 401
user.deleted_at = datetime.now(timezone.utc)
```

Зона `.invalid` зарезервирована (RFC 2606) — такого адреса не существует,
это не чьи-то данные. Подпись в документах — `full_name()` → «Удалённый
пользователь».

Добавляешь новую таблицу с ПДн и FK на `users` — добавь её очистку в
`app/services/account_deletion.py`.

## Сроки хранения

Данные, которые копятся сами по себе (журналы), должны иметь срок. Задача
планировщика `enforce_data_retention` раз в сутки:

```python
delete(SecurityAuditLog).where(SecurityAuditLog.created_at < now - timedelta(days=365))
update(AdEvent).where(AdEvent.created_at < now - timedelta(days=183)).values(ip=None, ...)
```

Событие рекламы не удаляется, а обезличивается: агрегаты показов нужны для
отчётности, а IP — нет. Сроки — в `app/services/retention.py`; менять
только вместе с разделом 11 Политики.

Логи контейнеров тоже содержат IP — их объём ограничен ротацией `json-file`
в `docker-compose.prod.yml` (без неё логи растут бесконечно).

## Трансграничная передача

Любой запрос из браузера посетителя на зарубежный сервер передаёт туда его
IP — это трансграничная передача (ст. 12 152-ФЗ). Политика утверждает, что
её нет, поэтому:

- шрифты — `@fontsource` (из своего бандла), не Google Fonts;
- иконки — только офлайн-набор `icon-sets.ts`; незарегистрированная иконка
  не рендерится вместо запроса к `api.iconify.design`;
- счётчики, Sentry SaaS, CDN — только после правки Политики.

## Маркировка рекламы

Не ПДн, но рядом по смыслу: интернет-реклама обязана нести пометку
«Реклама», сведения о рекламодателе и идентификатор `erid` из ОРД
(ст. 18.1 Закона о рекламе). Фильтр в `repositories/ad.pick_banner`:

```python
AdBanner.erid.is_not(None),  # немаркированный баннер не показываем вообще
```
